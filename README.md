# STEENIE Browser 2.1

A Brave-inspired Android browser built with Java and Android System WebView.

## Visual refresh
- Cinematic photographic start-page wallpapers with dark overlays and glass-effect panels.
- Brand-coloured SVG shortcut icons for Google, Gmail, YouTube, GitHub, Wikipedia, Facebook, Instagram and Reddit.
- Refined search field, typography, spacing, status indicators and responsive shortcut grid.
- Four selectable start-page backgrounds remain available from the browser menu.

## Existing browser features
- Multiple tabs and private tabs.
- Gmail shortcut (Google sign-in occurs on Google's website; credentials are not stored by this app).
- Bookmarks, local history, downloads and desktop-site toggle.
- Basic tracker-domain blocking toggle.
- Android System WebView rendering.

## Build
Open this project in Android Studio or use the included GitHub Actions workflow. The project uses Android Gradle Plugin 8.7.3, compile SDK 35 and Java source.

Private tabs reduce local persistence but do not provide full anonymity. Tracker blocking uses a small built-in domain list and is not a complete ad blocker.
